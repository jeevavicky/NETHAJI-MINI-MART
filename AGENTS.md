# Project Rules & Instructions

## Preservation of Store Configurations & Custom Changes
- **Admin Approval Mandate**: Do not overwrite, reset, remove, or modify any user-defined store configurations, custom products, categories, banners, settings, or layout adjustments without explicit confirmation and approval from the administrator.
- **Data Integrity**: Preserve all live customizations made through the Admin Panel (including custom catalogs, pricing, banners, contact details, and theme configurations) across all future iterations and repurchases.
- **Incremental & Non-Destructive Updates**: All new features or code modifications must be non-destructive and backward-compatible with the active store setup.
